# Contributing to JustSpeak

Thanks for your interest. The project is in early development; please open an issue before large changes.

## Workflow

1. Open an issue describing the problem or proposal.
2. Fork the repository and create a topic branch.
3. Keep changes focused; update docs when behavior changes.
4. Add tests for behavior changes when the project has a test setup.
5. Open a pull request using the template.

## Code of conduct

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Development setup

The technology stack is not finalized yet. Setup instructions will be added with the v0.1 code scaffold.
