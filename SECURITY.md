# Security Policy

## Supported versions

JustSpeak is pre-release. Security fixes are applied to the latest development
branch.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub Security
Advisories ("Report a vulnerability") or contact the maintainer directly.

## Scope and privacy

- v0.1 processes microphone audio. The project must document whether audio is
  processed locally or sent to a cloud ASR provider.
- Do not log raw audio or transcripts by default.
- v0.2 desktop control will require explicit permissions; the permission model
  must be documented and reviewed before release.

This file will be expanded before the first public release.
