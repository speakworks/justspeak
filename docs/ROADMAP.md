# Roadmap

## v0.1 — JustSpeak

- High-quality real-time desktop dictation.
- Local-first processing where feasible; optional cloud ASR.
- Clean punctuation, filler-word removal, personal vocabulary.
- One repository: `speakworks/justspeak`.

## v0.2 — SpeakPilot

- Voice-controlled desktop agent built on the same transcription core.
- Explicit permission model for desktop actions.
- Second repository `speakworks/speakpilot` only when the split criteria in
  [ADR-0001](ADR-0001-core-boundary.md) are met.

## Non-goals for v0.1

- Full desktop automation.
- Multi-user/team features.
- A hosted SaaS.
