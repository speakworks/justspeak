JustSpeak

Just speak. It types.

An open-source desktop speech-to-text tool. Speak naturally, and clean text appears at your cursor — no cloud required unless you choose it.

View on GitHub Read the roadmap

What it does

Voice-first dictation

Speak instead of typing. Text lands wherever your cursor is.

Clean output

Punctuation, filler-word removal, and a personal vocabulary.

Local-first

On-device processing where feasible; cloud engines are optional.
